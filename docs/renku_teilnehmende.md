# Renku im KI-Kompass

## Was ist Renku?

[Renku](https://renkulab.io) ist eine Plattform des Swiss Data Science Center, auf der Code direkt im Browser läuft. Sie brauchen nichts zu installieren.

Das Renku-Projekt **agentic-workshop-eth-staff** ist bereits eingerichtet:

- Es ist mit diesem Repository verbunden; Notebooks, Code und Dokumente sind in jeder Session vorhanden.
- Alle Python-Pakete sind installiert.
- Ein OpenAI-API-Key ist hinterlegt und für die Dauer des KI-Kompass aktiv.

## Was ist eine Session?

Eine Session ist Ihre persönliche Arbeitsumgebung in Renku: ein Rechner in der Cloud mit JupyterLab und einer eigenen Kopie des Repositorys.

- **Starten:** Projekt öffnen, anmelden und bei der Session auf **Launch** klicken. Der Start dauert einige Minuten.
- **Notebooks:** im Dateibrowser `ki-kompass-conversational-toolkit/backend/notebooks/german/` öffnen und mit `T01_baseline_rag.ipynb` beginnen. Der erste Durchlauf von T01 dauert einige Minuten, weil alle Dokumente verarbeitet werden.
- **Eigene Änderungen:** Sie können Notebooks und Code frei ändern und ausprobieren. Die Änderungen gelten nur in Ihrer Session; andere Teilnehmende sehen sie nicht, und das Repository bleibt unverändert.
- **Pausieren:** Nach einer Zeit ohne Aktivität wird die Session automatisch pausiert. Über **Resume** läuft sie mit dem gespeicherten Stand weiter.
- **Speichern:** Änderungen sind nicht dauerhaft gesichert. Wird eine Session beendet oder gelöscht, gehen sie verloren. Wichtige Dateien deshalb herunterladen (Rechtsklick auf die Datei, **Download**).

## Bei Problemen

- Notebook reagiert nicht: **Kernel > Restart Kernel** und die Zellen von oben erneut ausführen.
- Session startet nicht oder hängt: Session beenden und neu starten. Eigene Änderungen vorher herunterladen.
