# KI-Kompass: RAG-Workshop

Willkommen! In diesem Projekt arbeiten Sie mit den Notebooks des KI-Kompass, direkt im Browser. Sie brauchen nichts zu installieren.

## Was ist Renku?

Renku ist eine Plattform des Swiss Data Science Center, auf der Code in der Cloud läuft. Dieses Projekt ist bereits vollständig eingerichtet:

- Es ist mit dem Repository des Workshops verbunden; Notebooks, Code und Dokumente sind in jeder Session vorhanden.
- Alle Python-Pakete sind installiert.
- Ein OpenAI-API-Key ist hinterlegt und für die Dauer des KI-Kompass aktiv.

## Was ist eine Session?

Eine Session ist Ihre persönliche Arbeitsumgebung: ein Rechner in der Cloud mit JupyterLab und einer eigenen Kopie des Repositorys.

- **Starten:** Auf dieser Seite bei der Session auf **Launch** klicken. Der Start dauert einige Minuten.
- **Notebooks:** In JupyterLab `ki-kompass-conversational-toolkit/backend/notebooks/german/` öffnen und mit `T01_baseline_rag.ipynb` beginnen. Der erste Durchlauf von T01 dauert einige Minuten, weil alle Dokumente verarbeitet werden.
- **Eigene Änderungen:** Notebooks und Code dürfen Sie frei ändern. Die Änderungen gelten nur in Ihrer Session; andere Teilnehmende sehen sie nicht.
- **Pausieren:** Nach einer Zeit ohne Aktivität wird die Session automatisch pausiert. Mit **Resume** auf dieser Seite geht es mit dem gespeicherten Stand weiter.
- **Speichern:** Änderungen sind nicht dauerhaft gesichert. Wird die Session beendet oder gelöscht, gehen sie verloren. Wichtige Dateien deshalb in JupyterLab herunterladen (Rechtsklick auf die Datei, **Download**).

## Bei Problemen

- Notebook reagiert nicht: **Kernel > Restart Kernel** und die Zellen von oben erneut ausführen.
- Session startet nicht oder hängt: Session auf dieser Seite beenden und neu starten. Eigene Änderungen vorher herunterladen.
